1. Connect an AI model

SceneVoice Cloud

SceneVoice Cloud describes videos with the project’s own key, so there is nothing to set up.

When a video’s descriptions are complete, their text is sent to the SceneVoice cache. Never pictures, questions or who you are.

For SceneVoice Cloud Plus or an organisation licence. Keys look like svl-XXXX-XXXX-XXXX.

Gemini (Google)

SceneVoice uses Google's Gemini model to watch the video and write descriptions. You use your own free API key, so there is no account and no subscription.

  1. Open Google AI Studio and sign in with a Google account: Get a Gemini key at Google AI Studio (opens in a new tab)
  2. Choose “Create API key” and copy it.
  3. Paste it below and press Save and test.

2. Descriptions

When a description does not fit
Detail
How much to describe

Titles, names, slides, chart figures, prices, contact details, code and menus, word for word and before other descriptions. Text you already hear in the dialogue is not read again.

By video type

By default, entertainment keeps playing with brief descriptions of the essentials only, so the pace is not broken and quiet moments stay quiet; tutorials and explainers pause for detailed descriptions, so nothing on screen is missed. Other videos use the settings above. A mode, detail or amount you choose yourself (above, in the popup or with a shortcut) always comes first. The type comes from the video’s YouTube category and title, and from Gemini once descriptions exist.

5. Saved descriptions and privacy

Usage today

    Counted on this computer only, from the token counts the model reports, and starts again at midnight. The estimate uses paid-tier list prices; a free-tier Gemini key is not charged.

    How much video SceneVoice may describe per day, every model together, counted on this computer. When it is reached, no new descriptions start until tomorrow; questions still work.

    • With your own key, SceneVoice has no server and no account, and nothing is sent to the developer. It never collects analytics. SceneVoice Cloud, if you turn it on, is an optional relay run by the project; the next point says what it receives.
    • SceneVoice Cloud is off until you press “Start free”. With it on, requests go to api.scenevoice.app with an anonymous device token instead of a key, and the relay passes them to Gemini. Per token it keeps only how many seconds of video were described today, the plan and any licence key, plus the finished text of a video’s descriptions when sharing is on. It never keeps pictures, your questions, the answers or your IP address, and does not log requests. “Stop using Cloud” removes the token.
    • To create descriptions or answer a question, the YouTube video's address, title, channel and description, your question and the recent descriptions are sent to the Gemini API with your key. To describe a moment again, the description you marked as wrong is sent too. Google's terms for the Gemini API apply.
    • Descriptions are saved on this computer so a video is described only once.
    • With Qwen, or on Bilibili, pictures taken from the playing video are sent instead of its address.
    • The descriptions you mark as wrong are recorded only on this computer, so the corrected versions are kept. They are never sent to the developer, and are stripped before a video’s descriptions are shared. The record is deleted with the saved descriptions.

    6. Restore defaults
