1. Connect an AI model

Which model describes each site

Gemini watches a whole YouTube video by its link.

Gemini (Google)

SceneVoice uses Google's Gemini model to watch the video and write descriptions. You use your own free API key, so there is no account and no subscription.

  1. Open Google AI Studio and sign in with a Google account: aistudio.google.com/apikey
  2. Choose “Create API key” and copy it.
  3. Paste it below and press Save and test.

Your key is stored only on this computer and is sent only to the Gemini API address below.

The recommended model is chosen automatically. Flash models are fast and inexpensive.

Advanced

Change only if you use a compatible relay, for example where Google services are not reachable. The relay will see your key and requests.

Qwen (Alibaba Cloud Model Studio)

Qwen can be used from mainland China.

  1. Open the Alibaba Cloud Model Studio console and sign in: bailian.console.aliyun.com
  2. Create an API key there and copy it.
  3. Paste it below and press Save and test.

Your key is stored only on this computer and is sent only to the Qwen API address below.

It must understand pictures.

2. Descriptions

When a description does not fit
Detail
How much to describe

Titles, names, slides, chart figures, prices, contact details, code and menus, word for word and before other descriptions. Text you already hear in the dialogue is not read again.

By video type

By default, entertainment keeps playing with brief descriptions of the essentials only, so the pace is not broken and quiet moments stay quiet; tutorials and explainers pause for detailed descriptions, so nothing on screen is missed. Other videos use the settings above. A mode, detail or amount you choose yourself (above, in the popup or with a shortcut) always comes first. The type comes from the video’s YouTube category and title, and from Gemini once descriptions exist.

Entertainment: films, music, vlogs, games
Tutorials and explainers: lessons, how-to, science, news with charts

5. Saved descriptions and privacy

  • SceneVoice has no server and no account. It does not collect analytics.
  • To create descriptions or answer a question, the YouTube video's address, title, channel and description, your question and the recent descriptions are sent to the Gemini API with your key. To describe a moment again, the description you marked as wrong is sent too. Google's terms for the Gemini API apply.
  • Descriptions are saved on this computer so a video is described only once.
  • With Qwen, or on Bilibili, pictures taken from the playing video are sent instead of its address.
  • The descriptions you mark as wrong are recorded only on this computer, so the corrected versions are kept. There is no feedback server: nothing is sent to the developer. The record is deleted with the saved descriptions.

6. Restore defaults

Put every description, voice and sound setting back the way it was when you installed SceneVoice. Your API key, model and saved descriptions stay. Keyboard shortcuts stay too; change them on Chrome’s shortcuts page.
