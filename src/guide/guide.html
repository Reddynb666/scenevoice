How to get an API key

SceneVoice is free, but the AI model that watches the video needs a key of your own. Pick the model for the site you watch. Each step below is one thing to do; the sites change their pages from time to time, so a button may be named slightly differently.

Back to SceneVoice settings

Gemini key (for YouTube)

Free: no card is needed. The free tier has a daily limit, which is enough for everyday watching; it resets the next day. Gemini needs Google to be reachable from where you are.

  1. Open Google AI Studio: Google AI Studio API keys page (opens in a new tab)
  2. Sign in with a Google account. If you have none, choose “Create account” first.
  3. The first time, you are asked to accept the terms of service. Check the box and continue.
  4. Find the button “Create API key”. With a screen reader, jump between buttons (B in NVDA and JAWS browse mode; the rotor in VoiceOver) or search the page for “Create API key”.
  5. If you are asked to choose a Google Cloud project, pick the one offered, or “Create project”.
  6. A long key appears, starting with “AIza”. Press the “Copy” button next to it.
  7. Come back to SceneVoice settings, paste the key into “Gemini API key” and press “Save and test”. When it works you hear which model will be used.

Qwen key (for Bilibili, and from mainland China)

New accounts usually get a free allowance; the console shows how much is left. After that it is charged to your Alibaba Cloud account by use. Setting a budget alert in the Alibaba Cloud billing centre is a good idea.

  1. Open the Alibaba Cloud Model Studio console: Model Studio console (opens in a new tab)
  2. Sign in with an Alibaba Cloud account, or register with a phone number. A Taobao or Alipay account can also sign in.
  3. Complete real-name verification when asked (for example with Alipay). Alibaba Cloud requires it before a key can be used.
  4. The first time, the console asks you to activate Model Studio. Activating is free; use is charged afterwards.
  5. Find “API-KEY” (key management) and choose “Create API key”.
  6. A key starting with “sk-” appears. Copy it.
  7. Come back to SceneVoice settings, paste the key into “Qwen API key” and press “Save and test”.

Your key stays with you

The key is stored only on this computer and sent only to the model's own address. With your own key, SceneVoice has no server in that path and never sees it. Do not share the key with others: whoever has it can use your quota.
