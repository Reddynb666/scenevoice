Audio description for YouTube and Bilibili, through your own screen reader

Audio description for YouTube and Bilibili videos, in the pauses, through your own screen reader. Free and open source.

SceneVoice is a browser extension for Chrome and Edge, made for blind and low-vision viewers. It watches the video with an AI model, writes short descriptions of what is on screen, and reads them between lines of dialogue — in your screen reader's voice, at your speed, on your braille display.

It works on public videos. Live streams, private or age-restricted videos and paid or members-only (DRM-protected) videos cannot be described, and SceneVoice says so when it meets one. Bilibili support is experimental: it is new and has had less testing than YouTube.

How it works

  1. Install the extension in Chrome or Edge and add a key for the model, following a guide written for screen reader users: a Gemini key from Google for YouTube (it has a free tier), or a Qwen key from Alibaba Cloud for Bilibili (billed by use to your own account).
  2. Open a video and press Alt+Shift+D. SceneVoice says what it is doing at every step. The first part is usually ready within a minute; you hear "You can start watching".
  3. Descriptions arrive in the pauses. Each moment is written in three lengths; SceneVoice reads the longest one that fits the silence and keeps quiet rather than talk over dialogue. On-screen text is read word for word. If you prefer, it pauses the video and reads everything.
  4. Ask a question. Press Alt+Shift+Q, type "who is speaking?" or "what does the sign say?", and get an answer about that exact moment. If a description is wrong, say so, and that moment is described again.

Install

Works in Chrome, Edge, Brave and other Chromium browsers, version 116 or newer. Store listings are on the way; until they are live, the extension comes from a GitHub release, which works in every one of these browsers.

Install version 1.2.0 or later; do not install version 1.1.0. On its welcome page, 1.1.0 shows “Start free” (SceneVoice Cloud), which points at an address that was never the project's. The fix is in the version after it, 1.2.0. If the Releases page does not list 1.2.0 yet, use the web player until it does.

Chrome Web Store (coming soon) Edge Add-ons (coming soon) GitHub Releases (version 1.2.0 or later) Gitee, for mainland China (coming soon)

From a GitHub release, version 1.2.0 or later: download the zip, unzip it, open chrome://extensions (edge://extensions in Edge), turn on Developer mode, choose "Load unpacked" and pick the unzipped folder. The welcome page then opens: hear a sample, then follow “Add my key in settings” and the settings page opens at the key field. The README has the full steps, including how to get a key. For screen reader users in mainland China who would like to test it there is a guide in Chinese, written to be read with a screen reader: what the test is, how to take part, and the steps.

Who it is for and what it costs

For anyone who is blind or has low vision and watches YouTube or Bilibili; for the people who watch with them; and for schools, libraries and employers who need described video. The extension is free and open source (MIT licence) and has no account. Today it talks only to the model you chose, with your own key. SceneVoice Cloud, an optional relay for people without a key, is planned and not open; nothing below marked “planned” can be had yet.

Your own key — free, always
Bring a Gemini key (YouTube) or a Qwen key (Bilibili). Every feature, no limits from us, nothing leaves your computer except the request to the model. This is the whole product today.
SceneVoice Cloud, free allowance — planned
For people who do not want to open an API console: a daily allowance of new descriptions (planned: 60 minutes of video a day), plus unlimited playback of descriptions that someone has already generated for the same video. No account; the extension would get an anonymous token. Not open yet: there is no button for it in the web player, or in the extension from version 1.2.0 on.
SceneVoice Cloud Plus — planned
For heavy use: more minutes, faster generation, detailed descriptions for long videos. Not on sale. Planned price: US$4 a month or US$36 a year; in mainland China ¥9.9 a month or ¥88 a year. The plan is that people in hardship get it free, no proof asked.
Organisations — planned
Schools for the blind, libraries, university disability services, rehabilitation centres, employers: a managed key, a budget cap, usage reports and an accessibility conformance report (VPAT). None of this exists yet. Planned price: US$3 to 5 per seat per year; in mainland China, per school or library by agreement.

Nothing about accessibility is ever behind a paywall. Screen reader output, keyboard control, the pause mode, the question dialog and every setting stay free, and the own-key path is never slowed down or cut back.

Privacy

  • No account, no tracking. There are no analytics, usage statistics, crash reports or identifiers, and nothing you do is sent to the developer: the web player, and the extension from version 1.2.0 on, contact no SceneVoice server at all. SceneVoice Cloud is planned and not open. When it opens, and only for people who choose it, requests will go through a relay run by the project, on a domain the project holds, with an anonymous device token; the relay has no address yet, and the privacy policy below says what it would keep and what it would never keep. This website has no analytics either, and sets no cookies.
  • The video is never recorded or uploaded. With Gemini on YouTube, the request carries the video's address, title and the time span to describe, so the model reads the public video itself. With Qwen, or on Bilibili, small pictures of the frame (at most 640 pixels wide) are sent instead, and kept only in the tab's memory for a minute or two.
  • Your key stays yours. It is kept in the browser's local extension storage, travels only in a request header, is never placed in a web address, and never enters the YouTube or Bilibili page.
  • Only the model you chose sees a request. Requests go from your browser to Google's Gemini API or to Alibaba Cloud's Model Studio, under their terms, and to no one else. The Qwen address SceneVoice uses by default is Alibaba Cloud's service in mainland China.
  • Everything is on your computer and you can delete it. Descriptions, corrections and settings are stored locally; the settings page shows what is kept and deletes it in one step.

The full privacy policy lists every request and every permission, and why. SceneVoice's use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements; the policy says how.

For organisations and creators

Planned, not available yet: a way for schools for the blind, public libraries, university disability services and employers to give SceneVoice to everyone at once, with one managed key, a budget cap and a usage report, and no personal data about the viewers. Also planned: licences for video platforms and screen reader makers to use the description engine and a shared cache, so that a popular video is described once and heard by everyone. If one of these would help you, tell us now: it decides what is built first.

Creators and educators: your viewers can already describe your public videos themselves, with nothing from you. A described track to publish with the video is on the roadmap.

To talk about an organisation or platform licence, open an issue on GitHub. There is no e-mail address for this yet.

Boilerplate

SceneVoice is a free, open-source browser extension that adds AI audio description to YouTube and Bilibili videos for blind and low-vision viewers. Press one key on a public video and, usually within a minute, short descriptions of what is on screen are read in the pauses between dialogue — through the viewer's own screen reader, or a built-in voice. Bilibili support is experimental. Descriptions follow audio description guidelines: what is visible, on-screen text word for word, and "hard to see" when it is. Viewers can ask a question about any moment and correct a wrong description. SceneVoice has no account; it runs in the browser with the viewer's own model key and no server of its own (an optional SceneVoice Cloud relay is planned and not open). Source code is on GitHub under the MIT licence.
