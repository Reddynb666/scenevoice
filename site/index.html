Audio description for YouTube and Bilibili, through your own screen reader

Audio description for any YouTube or Bilibili video, in the pauses, through your own screen reader. Free and open source.

SceneVoice is a browser extension for Chrome and Edge, made for blind and low-vision viewers. It watches the video with an AI model, writes short descriptions of what is on screen, and reads them between lines of dialogue — in your screen reader's voice, at your speed, on your braille display.

How it works

  1. Install the extension in Chrome or Edge and add a key for the model (free from Google for YouTube, from Alibaba Cloud for Bilibili), following a guide written for screen reader users.
  2. Open a video and press Alt+Shift+D. SceneVoice says what it is doing at every step. The first part is ready in about half a minute; you hear "You can start watching".
  3. Descriptions arrive in the pauses. Each moment is written in three lengths; SceneVoice reads the longest one that fits the silence and keeps quiet rather than talk over dialogue. On-screen text is read word for word. If you prefer, it pauses the video and reads everything.
  4. Ask a question. Press Alt+Shift+Q, type "who is speaking?" or "what does the sign say?", and get an answer about that exact moment. If a description is wrong, say so, and that moment is described again.

Install

Works in Chrome, Edge, Brave and other Chromium browsers, version 116 or newer. Store listings are on the way; until they are live, the GitHub release works in every one of these browsers.

Chrome Web Store (coming soon) Edge Add-ons (coming soon) GitHub Releases Gitee, for mainland China (coming soon)

From a GitHub release: download the zip, unzip it, open chrome://extensions, turn on Developer mode, choose "Load unpacked" and pick the unzipped folder. The welcome page then opens: hear a sample, then choose “My own key” and the settings page opens at the key field (SceneVoice Cloud will be offered there once it is live). The README has the full steps, including how to get a free key.

Who it is for and what it costs

For anyone who is blind or has low vision and watches YouTube or Bilibili; for the people who watch with them; and for schools, libraries and employers who need described video. The extension is free and open source (MIT licence), with no account and, with your own key, no server of its own; SceneVoice Cloud, when it opens, is an optional relay (see Privacy).

Your own key — free, always
Bring a Gemini key (YouTube) or a Qwen key (Bilibili). Every feature, no limits from us, nothing leaves your computer except the request to the model. This is the whole product today.
SceneVoice Cloud, free allowance — planned
For people who do not want to open an API console: a daily allowance of new descriptions (planned: 60 minutes of video a day), plus unlimited playback of descriptions that someone has already generated for the same video. No account; the extension gets an anonymous token. Not open yet.
SceneVoice Cloud Plus — planned
For heavy use: more minutes, faster generation, detailed descriptions for long videos. Planned price: US$4 a month or US$36 a year; in mainland China ¥9.9 a month or ¥88 a year. People in hardship get it free, no proof asked.
Organisations — planned
Schools for the blind, libraries, university disability services, rehabilitation centres, employers: a managed key, a budget cap, usage reports and an accessibility conformance report (VPAT). Planned price: US$3 to 5 per seat per year; in mainland China, per school or library by agreement.

Nothing about accessibility is ever behind a paywall. Screen reader output, keyboard control, the pause mode, the question dialog and every setting stay free, and the own-key path is never slowed down or cut back.

Privacy

  • No account, no tracking. With your own key, SceneVoice has no backend and nothing you do is sent to the developer; there are no analytics, usage statistics, crash reports or identifiers. SceneVoice Cloud (optional, not open yet) will send requests through the project's relay at api.scenevoice.app with an anonymous device token; the privacy policy below says what the relay keeps and what it never keeps. This website has no analytics either, and sets no cookies.
  • The video is never recorded or uploaded. With Gemini on YouTube, the request carries the video's address, title and the time span to describe, so the model reads the public video itself. With Qwen, or on Bilibili, small pictures of the frame (at most 640 pixels wide) are sent instead, and kept only in the tab's memory for a minute or two.
  • Your key stays yours. It is kept in the browser's local extension storage, travels only in a request header, is never placed in a web address, and never enters the YouTube or Bilibili page.
  • Only the model you chose sees a request. With your own key, requests go to Google's Gemini API or Alibaba Cloud's Model Studio, under their terms, and nowhere else; with SceneVoice Cloud they go to the relay, which forwards them to the model without logging them. A Qwen key with the mainland China address keeps requests inside mainland China.
  • Everything is on your computer and you can delete it. Descriptions, corrections and settings are stored locally; the settings page shows what is kept and deletes it in one step.

The full privacy policy lists every request and every permission, and why.

For organisations and creators

Schools for the blind, public libraries, university disability services and employers can give SceneVoice to everyone at once: one managed key, a budget cap, and a usage report, with no personal data about the viewers. Video platforms and screen reader makers can license the description engine and the shared cache, so a popular video is described once and heard by everyone.

Creators and educators: your viewers can describe your videos today, with nothing from you. If you would like a described track to publish with the video, that is on the roadmap.

Write to us about an organisation or platform licence (address to be set), or open an issue on GitHub.

Boilerplate

SceneVoice is a free, open-source browser extension that adds AI audio description to YouTube and Bilibili videos for blind and low-vision viewers. Press one key on any video and, about half a minute later, short descriptions of what is on screen are read in the pauses between dialogue — through the viewer's own screen reader, or a built-in voice. Descriptions follow audio description guidelines: what is visible, on-screen text word for word, and "hard to see" when it is. Viewers can ask a question about any moment and correct a wrong description. SceneVoice has no account; with the viewer's own model key it runs in the browser with no server of its own (an optional SceneVoice Cloud relay is planned). Source code is on GitHub under the MIT licence.
