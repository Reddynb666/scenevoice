YouTube 和哔哩哔哩的口述影像，用你自己的读屏来听

YouTube 和哔哩哔哩视频的口述影像，放进对白空隙，用你自己的读屏朗读。免费、开源。

SceneVoice（声景）是一个 Chrome / Edge 浏览器扩展，为盲人和低视力观众而做。它让 AI 模型看视频，写出画面的简短描述，然后趁对白之间的空隙读出来——用的是你读屏软件自己的声音、你习惯的语速，盲文显示器上也能看。

它适用于公开视频。直播、私享或有年龄限制的视频，以及付费、会员专享（受 DRM 保护）的视频目前无法描述，遇到时 SceneVoice 会直接告诉你。哔哩哔哩的支持还是实验性的：这部分是新做的，实测不如 YouTube 充分。

先听听看

下面是三条示例口述，按 SceneVoice 实际的放法：先是一句对白，空隙里跟一条描述。你平时用什么听，就按哪个按钮；读到的文字也会同步显示在下面。

不想安装也能试：网页播放器接收一个 YouTube 链接，用你自己的 Gemini 密钥，直接在这个浏览器里描述视频。

每出现一行，读屏就读一行。SceneVoice 默认就是这样工作的。

改用浏览器自带的语音朗读。它朗读期间，下面的文字不会再交给读屏播报，两个声音不会抢着说。需要 JavaScript，并且浏览器要支持语音合成。

一个穿红色大衣的女人把报纸顶在头上挡雨，跑过湿漉漉的街道。

对白。

屏幕文字：“第二章 码头”。天刚亮，一艘渔船绕过防波堤。

对白。

他从口袋里掏出一封折好的信，犹豫了一下，没拆开又放了回去。

怎么用

  1. 安装扩展，在 Chrome 或 Edge 里装好后，照着专为读屏用户写的分步指南添加一个模型 Key：哔哩哔哩用阿里云的通义千问（按用量记在你自己的阿里云账号上），YouTube 用谷歌的 Gemini（有免费额度）。
  2. 打开一个视频，按 Alt+Shift+D。 SceneVoice 每一步都会播报自己在做什么。前面一段通常一分钟内就绪，你会听到“可以开始看了”。
  3. 口述放在对白空隙里。 每个时刻都有简洁、标准、详细三种长度，SceneVoice 挑能放进空隙的最长那条；放不下就不说，不压对白。屏幕上的文字按原文逐字读。你也可以让它暂停视频、把整条描述读完。
  4. 随时提问。 按 Alt+Shift+Q，输入“谁在说话？”“牌子上写的什么？”，就能得到针对这一刻的回答。描述说错了，告诉它一声，这一段会重新描述。

安装

支持 Chrome、Edge、Brave 等 Chromium 内核浏览器，116 及以上版本。商店版本正在准备；在此之前，扩展要从 GitHub 的发布包安装，这些浏览器都能用。Edge 加载项和 Gitee 镜像上线后，中国大陆用户建议从那里安装。

请安装 1.2.0 或更新的版本，不要安装 1.1.0。1.1.0 的欢迎页上有“免费开始”（SceneVoice 云端），它指向的地址从来不是项目的。这个问题在它之后的版本 1.2.0 里修复。如果 Releases 页面上还没有 1.2.0，请先用网页播放器。

Chrome 应用商店（即将上线） Edge 加载项（即将上线） GitHub Releases（1.2.0 或更新的版本） Gitee 镜像，中国大陆（即将上线）

用 1.2.0 或更新版本的发布包安装：下载 zip 并解压，打开 chrome://extensions（Edge 是 edge://extensions），开启开发者模式，点“加载已解压的扩展程序”，选中解压后的文件夹。之后会打开欢迎页：先听一段示例，再按“去设置页添加我的密钥”，设置页就会在 Key 输入框打开。完整步骤和申请 Key 的方法见中文说明。想参加测试的读屏用户请看测试指南：里面写了测试是什么、怎样参加，步骤全程键盘操作，一步一句，适合用读屏来读。

适合谁、要花多少钱

给看 YouTube 和哔哩哔哩的盲人和低视力朋友，给陪他们一起看的人，也给需要口述影像的盲校、图书馆和用人单位。扩展本身免费、开源（MIT 协议），没有账号。现在它只用你自己的 Key，直接和你选的模型通信。SceneVoice 云端是给没有 Key 的人准备的可选中转，还在筹备，没有开放；下面标着“筹备中”的几档现在都还用不了。

自带 Key —— 永久免费
用你自己申请的通义千问 Key（哔哩哔哩）或 Gemini Key（YouTube）。全部功能，我们不设任何限制；除了发给模型的请求，什么都不离开你的电脑。今天的 SceneVoice 就是这一档。
SceneVoice 云端免费额度 —— 筹备中
给不想碰 API 控制台的人：每天一份新口述额度（计划每天 60 分钟视频），加上不限量地收听别人已经生成过的同一个视频的口述。不用注册，到时扩展会自动领一个匿名凭证。目前还没开放：网页播放器里没有它的按钮，扩展从 1.2.0 版起也没有。
SceneVoice 云端 Plus —— 筹备中
给重度用户：更多时长、优先生成、长视频的详细档。目前没有开售。计划价格：中国大陆每月 9.9 元或每年 88 元（微信、支付宝）；海外每月 4 美元或每年 36 美元。按计划，经济困难的朋友免费，不用出示任何证明。
机构许可 —— 筹备中
盲校、残联、图书馆、高校残障服务办公室、视障康复机构、用人单位：托管 Key、预算上限、用量报表和无障碍符合性报告（VPAT）。这些现在都还没有。计划价格：中国大陆按校、按馆商议；海外每人每年 3 到 5 美元。

凡是和无障碍有关的，永远不收费。 读屏输出、键盘操作、暂停模式、提问对话框和所有设置都免费；自带 Key 这条路永远不降速、不缩水。

隐私

  • 没有账号、不追踪。 没有统计、没有使用数据、没有崩溃报告、没有标识符，你做的任何事都不会发给开发者：网页播放器，以及 1.2.0 版起的扩展，都不联系 SceneVoice 的任何服务器。SceneVoice 云端还在筹备，没有开放。开放之后，只有选用它的人，请求才会经由项目自己运营的中转发送，中转会放在项目自己持有的域名下，请求携带匿名的设备凭证；中转现在还没有地址，下面的隐私政策写明了它到时保存什么、绝不保存什么。这个网站同样没有统计，也不设 Cookie。
  • 从不录制、不上传视频。 在哔哩哔哩上，或者用通义千问时，发出去的是画面的小尺寸截图（最宽 640 像素），只在标签页内存里保留一两分钟；在 YouTube 上用 Gemini 时，发出去的是视频地址、标题和要描述的时间段，由模型自己去读公开视频。
  • Key 是你自己的。 只存在浏览器本机的扩展存储里，只走请求头，绝不放进网址，也绝不进入哔哩哔哩或 YouTube 的网页。
  • 只有你选的模型能看到请求。 请求从你的浏览器直接发给阿里云百炼（通义千问）或谷歌的 Gemini API，按它们各自的条款处理，不经过其他任何一方。SceneVoice 默认使用的通义千问地址，是阿里云在中国内地的服务。
  • 一切都在你的电脑上，随时可以删。 口述、纠错记录和设置都存在本地，设置页能看到存了什么，一键全部删除。

完整的隐私政策列出了每一个请求和每一项权限，以及为什么需要（English）。SceneVoice 对用户数据的使用符合 Chrome 应用商店的用户数据政策，包括其中的 Limited Use（有限使用）要求，具体做法写在隐私政策里。

面向机构与创作者

还在筹备、现在没有：让盲校、公共图书馆、高校残障服务办公室和用人单位一次给所有人装上的办法，包括一个托管 Key、一个预算上限、一份用量报表，不涉及任何观众的个人信息。同样在筹备的，还有给视频平台和读屏软件厂商的授权：使用口述引擎和共享缓存，让热门视频只生成一次、所有人都能听。如果其中哪一项对你有用，现在就告诉我们，这会决定先做什么。

UP 主和老师们：你的视障观众现在就能自己给你的公开视频加口述，不需要你做任何事。把口述音轨随视频一起发布，这在路线图上。

想谈机构或平台授权，请在 GitHub 上提 issue。目前还没有专门的联系邮箱。

简介

SceneVoice（声景）是一个免费、开源的浏览器扩展，为盲人和低视力观众给哔哩哔哩和 YouTube 视频加上 AI 口述影像。在公开视频上按一个键，通常一分钟内，画面的简短描述就会在对白空隙里读出来——用观众自己的读屏软件，或者浏览器内置语音。哔哩哔哩的支持还是实验性的。描述遵循口述影像规范：只说看得见的，屏幕文字逐字读，看不清就说看不清。观众可以就任何一刻提问，也可以纠正说错的描述。SceneVoice 没有账号；它用观众自己的模型 Key，完全在浏览器里运行，没有自己的服务器（可选的 SceneVoice 云端中转还在筹备，没有开放）。源代码在 GitHub 上，MIT 协议。
