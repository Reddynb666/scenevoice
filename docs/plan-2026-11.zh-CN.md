# SceneVoice 2.0 计划：让全世界视障者都能用，并且能养活自己

日期：2026-11-04。基线：`feat/china-bilibili`（421 个单元测试、全部 e2e 通过）。
本文是执行计划，不是愿景书；每一条都对应代码或文件。

## 一、诊断：引擎很强，没有门

13 个并行审计代理读完全部代码和当前市场后，结论高度一致：

**做对的地方（市场上没有第二家）**
- 唯一一个"在你正在看的页面里、按一个键、整段视频、塞进对白空隙、用你自己的读屏朗读"的产品。YouDescribe 靠志愿者排队，PiccyBot / Seeing AI 要上传文件且只有手机版，FYEO 每个镜头要手动按（AppleVis 评分 2/5），JAWS Picture Smart 只看一帧，Omni Describer 离线批处理且同样要 API Key。
- 安全模型在同类里最强：Key 只在本机 `storage.local`（TRUSTED_CONTEXTS）、只走请求头、只从 offscreen worker 发出、消息发送方逐条白名单并有测试。
- 提示词遵循 ACB / DCMP 口述影像规范：不猜情绪、不编人名、屏幕文字逐字、不确定就说。

**致命问题（按用户遇到的顺序）**
1. **没有 Key 就一个字也听不到。** 从安装到第一句描述要 19 步、6 个系统（商店上架后 13 步）；中国用户还要支付宝人脸实名认证。没有试听、没有免费额度、没有示例。这是"全世界视障者"的第一堵墙。
2. **安装只能开发者模式。** 没上商店、没有 git tag、没有 Release，README 却让人去 Releases 页下载。版本号停在 1.0.0，CHANGELOG 里有约 40 条未发布改动。
3. **第一分钟就对读屏用户撒谎三次。** 无 Key 时按"描述此刻"/"提问"说"正在打开设置页"但没有打开；只有千问 Key 的中文用户上 YouTube 被告知"需要 Gemini Key"（反之亦然）；"连接成功，可以开始了"之后不说下一步。
4. **"不压对白"在默认配置下不成立。** 没有字幕时间轴时，代码把模型估计的间隙再**加** 0.5 秒余量（应该减）；截帧模式不确定时凭空填 `gap: 3`；新描述会直接切断正在朗读的上一条；读屏输出下"读完了"是定时器猜的，暂停模式会在读屏还在念时恢复播放。
5. **会替恶意网页花你的钱。** YouTube 内嵌 iframe 也注入脚本，`autoGenerate` 开着时，一个藏了 N 个静音 10 小时视频的网页能启动 N 个 Gemini 任务；没有任何花费上限，token 用量被直接丢弃。
6. **弹出面板每秒重读百分比、按钮隐藏后焦点掉到 body。** 读屏用户打开面板就被打断。
7. **"全世界"目前只有 en / zh_CN 界面；浏览器语言不在 12 种里的用户静默得到英文描述；Firefox 完全装不上。**

## 二、定位与商业模式

**一句话**：任何网络视频的即时口述影像，在你正在看的页面里，通过你自己的读屏。免费、开源、不要账号；想省事的人和机构付费。

**三层模式（开放内核 + 托管便利）**
| 层 | 对象 | 价格 | 包含 |
| --- | --- | --- | --- |
| 自带 Key（BYOK） | 极客、隐私优先、中国用户 | 永久免费，不限功能 | 现在的全部功能；无服务器 |
| SceneVoice Cloud 免费额度 | 所有不想碰 API 控制台的人 | 免费，每日额度（建议每日 60 分钟新描述 + 共享缓存无限） | 匿名按安装发 token，无账号 |
| SceneVoice Cloud Plus | 重度个人用户 | 海外 $4/月或 $36/年；中国 9.9 元/月或 88 元/年（微信/支付宝） | 更高额度、优先生成、长视频详细档；困难用户免证明减免 |
| 机构许可 | 盲校、残联、图书馆、大学残障服务办、VR 机构、雇主 | 按席位/年（海外 $3–5/人/年；中国按校/馆议价） | 托管 Key、管理台、预算上限、用量报表、VPAT |
| 平台/B2B | Bilibili、YouDescribe、读屏厂商、浏览器厂商 | 年费或分成 | 描述引擎 + 共享缓存 API，白标 |

**红线（写进 PRIVACY.md）**：不投广告、不卖观看数据、不把读屏输出或任何无障碍设置放进付费墙、BYOK 永不降级、Cloud 不保管用户自己的 Key、不留存画面帧与问题。

**为什么能赚钱**：单位成本每小时视频约 $0.16–0.35（Gemini 3.5 Flash-Lite / 3.8 Flash，2026-11 价目；默认 `FREE_MODELS` 下扩展会选 Flash，低端的 Flash-Lite 价位要把 `FREE_MODELS` 收窄到 lite 系列才成立），且共享缓存让热门视频只生成一次。机构预算真实存在（EAA 2025、ADA Title II 2027、中国《无障碍环境建设法》第 30 条点名"口述音轨"、"十五五"科技助残）。个人价位参考 PiccyBot $2.99/月、Ally Pro $10/月、JAWS 家庭版 $90/年。

**为什么能出名**：市场上没有能用的同类；AppleVis 在 2026 年 7 月有人发帖求的就是这个产品；Chrome 商店搜 "audio description" 只有差评工具。发布顺序：AppleVis 论坛 + Double Tap / NFB Access On 播客演示 → nvda-users、JAWS 邮件列表 → 争渡/保益 QQ 群 + Bilibili 视障 UP 主实测 → GAAD（5 月）或 CSUN（3 月）节点做 Product Hunt / Show HN。每一步都需要"装上就能听到"的零门槛路径，否则流量只烧一次。

## 三、路线图

### 阶段 1（本次会话开始，目标 1–2 周）：能被陌生人装上并在 2 分钟内听到描述

**Sprint A — 第一分钟不撒谎、不乱花钱（小时级）**
- 无 Key 时"描述此刻"/"提问"真的打开设置页，并定位到需要的那个 Key 字段。
- 哪个 Key 存在就用哪个模型（任一站点），切换时播报一次；第一次保存 Key 时自动设置两个站点的模型。
- 修正千问默认模型文案（qwen3-vl-plus）；"可以开始了"之后说下一步。
- 弹出面板：状态区只在状态变化时播报一次，百分比放进非 live 元素；生成/停止后焦点显式移到下一个控件。
- 直播区写入改成队列，不再吞掉连续两条状态。
- offscreen 调用加超时，不再无声卡死。
- iframe 内不自动生成、不自动续传；校验 `videoId / lang / duration`；同时任务数上限；每标签页请求限速。

**Sprint B — 口述不压对白（天级）**
- 模型估计的间隙改为**减** 0.5 秒余量（下限 0）；截帧模式不确定时视为 0（继续播放模式）或"需要暂停"（暂停模式）。
- 新描述不切断同级或更高优先级的描述：能等就等，等不到就丢。
- 读屏 + 暂停模式加 1.5 秒保险；推荐描述用内置语音、状态走读屏，并在指南里说明原因。
- 拖动进度条时停止朗读、忽略非当前 video 元素的事件。
- 迟到的截帧描述前加"刚才："。
- 链接模式把上一段的最后几条描述传给下一段，并在非开头段关闭"开场描述"规则。

**Sprint C — 零门槛（天到周）**
- 欢迎页 `welcome.html`：① 先听听看（零成本示例，用内置语音/读屏演示三条描述）② 选择来源：SceneVoice Cloud 免费额度 / 自己的 Key ③ 打开一个视频试试，并播报分配到的快捷键。设置页回归为设置页。
- 用量记账：保存 Gemini `usageMetadata` / 千问 `usage`，弹出面板显示"这个视频约 X"，设置页显示今日合计，可设每日上限。
- 429 区分"每分钟限速"与"当日配额用完"，后者直接换模型族。
- **SceneVoice Cloud 参考实现**（`server/`，Cloudflare Worker）：匿名按安装 token、每日额度、共享描述缓存（按视频 ID + 语言 + 版本）、Stripe 订阅 webhook、机构 license key；不保管用户 Key、不留存帧和问题。扩展端新增 provider `cloud`。**部署需要所有者的域名、Cloudflare 与 Stripe 账号。**

**Sprint D — 发布工程（天级）**
- 版本升到 1.1.0，CHANGELOG 切版；`release.yml`：打 tag → 测试 + e2e → 校验版本一致 → GitHub Release（zip + sha256 + sourcemap）→ 有密钥时自动上传 Chrome 商店 / Edge 加载项草稿。
- 商店文案改名覆盖哔哩哔哩与千问；补 Data Usage 答案；用 Playwright 自动生成 1280×800 截图与 440×280 宣传图；`PRIVACY.zh-CN.md`、`SECURITY.md`；CI 最小权限、超时、依赖锁定。
- 官网 `site/`（GitHub Pages，中英双语，读屏优先，一键"先听听看"）。

**Sprint E — 全世界（天级）**
- 描述语言跟随任何浏览器语言（改为拒绝名单），补 it / nl / pl / tr / vi / th / id / bn / ur / fa / uk / sw 的常量表。
- 语言文件按语言拆分，允许部分翻译并回退英文，打印覆盖率；新增 zh_TW、es、pt_BR、fr、de、ja、ko、ru、ar、hi、id、vi 界面（AI 初译，CONTRIBUTING 里标明待母语者复核）。

**Sprint F — 验证**
- e2e 增加：哔哩哔哩 + 模拟千问、zh-CN 界面、深色模式 axe、弹出面板各状态、空转写页。
- 对抗式代码评审每个 Sprint 的 diff。

### 阶段 2（上架后 1–2 个月）：真人验证与渠道
- 中英各 10 位视障测试者付费测试（CONTRIBUTING 清单；争渡/保益/NVDA/JAWS/VoiceOver）。
- Firefox 版本（offscreen / tts 抽象层，NVDA 用户约三分之一在 Firefox）。
- 共享缓存对外 API；YouDescribe、Be My Eyes Foundation、光明影院、中国盲协接洽。
- 申请：Google for Nonprofits 云额度、阿里云 OPC / 小有可为、腾讯技术公益、NIDILRR 类基金；Microsoft AI for Accessibility 需先向微软核实是否仍开放。

### 阶段 3：规模
- 更多平台（截帧模式理论上适用于任何可读 `<video>`：Vimeo、X、Twitch、央视频、西瓜）。
- 创作者导出 AD 音轨（SRT/WebVTT），对接 ADA Title II / EAA 合规买方。
- 安卓 / 与读屏厂商合作。

## 四、需要所有者亲自做的事（代码做不了）
1. 域名（建议 scenevoice.app / scenevoice.cn）、Cloudflare 账号、Stripe（海外）与微信/支付宝商户（中国，需主体）。
2. Chrome 商店开发者账号（$5）、Edge Partner Center、Gitee 实名。
3. 真实千问 Key 跑通 E1；真实读屏测试（F2）。
4. 中国站上线前的合规核实（生成式 AI 备案、PIPL、ICP）。
5. 决定是否把仓库公开、何时推送。

## 五、风险
- 大厂路线（Google Guided Vision、Be My Eyes Foundation 点名 live video description）：护城河是桌面浏览器 + 读屏原生 + 中国平台 + 开源信任 + 质量控制（密度、追问、纠错）。
- Gemini 3.x Flash 2027-01-01 涨价一倍：多模型 + 共享缓存对冲；免费档默认跑的是 Flash（两者都放行时扩展选 Flash），需要时由运营者把 `FREE_MODELS` 收窄到 Flash-Lite。
- 维护者单点：尽早招募盲人共同维护者，挂靠高校或基金会。
