## Name

SceneVoice: AI Audio Description for YouTube

## Summary (132 characters max)

EN: Audio description for any YouTube video, for blind and low-vision viewers. Works with your screen reader. Your own Gemini key.

## Description

**EN**

SceneVoice adds audio description to any YouTube video. Press Alt+Shift+D, and within about half a minute per five minutes of video you hear what is on screen — who enters, what they do, what the signs and title cards say — spoken in the pauses between dialogue by your own screen reader.

Made for screen reader users
• Works with NVDA, JAWS and VoiceOver: descriptions go to a live region, so you keep your voice, speed and braille display.
• Every control works from the keyboard. Every state is announced.
• A built-in voice is available for listeners without a screen reader.

Fits the pauses
• Every moment is written in three lengths. SceneVoice picks the longest that fits the silence, at your reading speed and playback rate.
• Or let it pause the video and read the full description. Or stay silent until you ask.

Describe now, ask anything
• Alt+Shift+S describes the current moment at once.
• Alt+Shift+Q opens a dialog: "Who is speaking?" "What does the sign say?" and you get an answer about that exact moment.
• Alt+Shift+L repeats the last description.

Reads on-screen text
• Title cards, burned-in captions, signs, slides and chat messages, with translation when needed.

Your key, your data
• You use your own free Gemini API key from Google AI Studio. No account, no subscription, no server, no analytics.
• Descriptions are saved on your computer, so a video is described only once.

Languages
• Interface in English and Simplified Chinese.
• Descriptions in English, Simplified and Traditional Chinese, Spanish, French, German, Portuguese, Japanese, Korean, Russian, Arabic and Hindi.

SceneVoice is free and open source (MIT). Descriptions are generated by an AI model and can be wrong; it is asked to say when it is unsure and never to invent names.

## Permission justifications (for the review form)

- `storage`, `unlimitedStorage`: store the user's API key, settings and generated description scripts locally. Scripts for long videos can exceed the default quota.
- `tts`: optional built-in voice output for users without a screen reader.
- `activeTab`: lets the toolbar popup tell whether the current tab is a YouTube video and show the right status.
- `offscreen` (reason `WORKERS`): hosts the worker that sends the long video-description requests to the Gemini API. These take 30–90 seconds, longer than a service worker may wait for a fetch, and running them in the YouTube page would expose the user's API key to the page and subject the requests to YouTube's page policies.
- Host `https://generativelanguage.googleapis.com/*`: the Gemini API that generates descriptions.
- Content script on `youtube.com`: follow playback, show the player button, overlay and question dialog.
- Optional host permissions: only requested if the user enters a custom API address (relay), and only for that origin.

Single purpose: provide audio description of YouTube videos for blind and low-vision users.

No remote code: all code ships in the package; the Gemini API returns data (JSON text), not code.
