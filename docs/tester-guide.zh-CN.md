# SceneVoice 测试指南（给使用读屏的朋友）

这是一份请读屏用户帮忙测试 SceneVoice 的指南。SceneVoice 是一个浏览器扩展，给视频加上口述影像：它让 AI 看画面，把画面上发生的事趁对白的空隙读给你听。

测试在哔哩哔哩上做，大约 20 到 30 分钟，全程只用键盘。你需要：一台 Windows 电脑，Edge 或 Chrome 浏览器，争渡读屏、保益读屏或 NVDA 中的任意一款，以及能打开哔哩哔哩的网络。不需要注册任何账号，也不用花钱。

这份指南每一步只做一件事。哪一步卡住了，不用硬试，把卡在哪里告诉我们，这本身就是最有用的反馈。

报名之后，我们会单独发给你四样东西：安装用的商店链接或压缩包，一把测试用的密钥，两个测试视频的链接，以及把回复发到哪里。这四样不会写在这个公开的页面上。

## 一、这是什么，我们想知道什么

SceneVoice 是一个浏览器扩展。它让 AI 看视频画面，写出简短的描述，再趁对白的空隙读给你听，也就是口述影像。默认由你自己的读屏来读。

这个扩展还没有读屏用户完整测试过。这一轮我们最想知道四件事：

1. 你的读屏会不会把口述读出来。口述是自动播报出来的，不是你用方向键读到的；有的读屏可能不读这种播报。
2. 快捷键在你的读屏和输入法下能不能用。
3. 用中文输入法提问会不会出问题。
4. 有没有两个声音同时说话，或者同一句话说两遍。

你听到的每一句原话，对我们都有用。回复发到哪里，报名时我们会告诉你。

## 二、会收集什么

1. 扩展不会自动收集任何东西。没有统计，没有账号，不会把你的操作发给我们。
2. 我们能读到的，只有你自己写下来、发给我们的回复。
3. 测试时，视频画面的缩小截图、视频标题和你输入的问题，会发给阿里云的通义千问模型，这是生成口述必需的。发送时用的是我们提供的测试密钥。
4. 测试密钥是我们专门准备的，记在项目所有者的阿里云账号上，测完就作废。你不需要注册阿里云，也不用花钱。
5. 扩展里有一句“不要把 Key 给别人”。这次是例外：这把密钥本来就是发给你测试用的。请不要再转给别人。

## 三、安装

有两种办法。如果我们给了你商店链接，用办法一；否则用办法二。

请只安装我们发给你的版本，版本号是 1.2.0 或更新。GitHub 上的 1.1.0 是旧版，请不要安装。

### 办法一：从 Edge 加载项商店安装

商店链接由我们单独发给你。没有收到链接，就用办法二。

1. 用 Edge 打开上面的链接。
2. 在页面上找到“获取”按钮，按回车。
3. 浏览器会问是否添加这个扩展。找到“添加扩展”按钮，按回车。
4. 稍等几秒，浏览器会自动打开一个新标签页，标题是“欢迎使用 SceneVoice”。
5. 如果没有自动打开，按 Ctrl+Tab 在标签页之间找一找。

### 办法二：加载解压的文件夹

压缩包由我们单独发给你，文件名以 scenevoice 开头。

1. 把压缩包解压到一个以后不会删除的文件夹，例如 D 盘下的 SceneVoice 文件夹。用你平时的解压软件就可以。
2. 确认这个文件夹里直接有一个叫 manifest.json 的文件。如果它在更里面一层，就记住里面那一层文件夹的位置。
3. 复制这个文件夹的完整路径，后面要粘贴。
4. 打开 Edge，按 Ctrl+L 到地址栏，输入 edge://extensions ，按回车。Chrome 用户输入 chrome://extensions 。
5. 按 Tab 键，直到听到“开发人员模式”。Chrome 里叫“开发者模式”。它是一个开关。
6. 如果它是关闭的，按空格把它打开。
7. 继续按 Tab 键，找到“加载解压缩的扩展”按钮，按回车。Chrome 里叫“加载已解压的扩展程序”，新版本也可能叫“加载未打包的扩展程序”。
8. 这时会打开一个选择文件夹的对话框。按 Alt+D 到对话框的地址栏，按 Ctrl+V 粘贴刚才复制的路径，按回车。
9. 按 Tab 键找到“选择文件夹”按钮，按回车。
10. 稍等几秒，浏览器会自动打开一个新标签页，标题是“欢迎使用 SceneVoice”。

关于按钮名称：上面这些名称是我们照着浏览器的中文界面写的，还没有用读屏逐一核对。你实际听到的如果不一样，请告诉我们。

关于重启浏览器后的提示：用办法二安装后，下次打开浏览器时，可能会弹出一个提示。

1. 提示的大意是“关闭开发人员模式下的扩展”。
2. 请不要按提示里关闭或停用扩展的按钮。
3. 按 Esc 关掉这个提示就可以。
4. 如果扩展还是被关掉了，回到 edge://extensions ，找到 SceneVoice，把它的开关重新打开。
5. 这个提示的确切文字我们还没有核对过。请告诉我们你听到了什么。

## 四、填入测试用的密钥

测试密钥由我们单独发给你，是一串以 sk- 开头的字符。

建议先做第五节的检查 1。它就在欢迎页上，不需要密钥。做完再回到这里。

1. 先复制我们发给你的密钥。
2. 回到“欢迎使用 SceneVoice”页面。
3. 在页面上找到“去设置页添加我的密钥”，按回车。
4. 设置页会打开，焦点应该落在“通义千问 API Key”输入框里。如果不在，按 Tab 键找到它。
5. 按 Ctrl+V 粘贴密钥。
6. 按 Tab 键找到“保存并测试”按钮，按回车。
7. 应该听到：“连接成功，当前模型：”，后面跟着模型的名字，然后是一句下一步该做什么的提示。
8. 如果听到的是“通义千问 API Key 无效”，或者别的话，或者什么也没听到，请把原话记下来告诉我们。

## 五、九项检查

按重要程度排序。时间不够的话，做到哪一项算哪一项，前三项最重要。

每一项请记下三样：你按了什么，原话听到了什么，你觉得应该听到什么。

### 检查 1：按“听一段示例”后，读屏有没有读出来

这一项在“欢迎使用 SceneVoice”页面上做，不需要密钥。

1. 在页面上找到“用什么来听”这一组选项，确认选中的是“我的读屏软件”。
2. 找到“听一段示例”按钮，按回车。
3. 按完以后不要再按任何键，听 20 秒左右。
4. 应该依次听到五句话。第一句是“标题：怎样给植物换盆。”，最后一句以“示例结束”开头。
5. 请记下：听到了几句；有没有漏掉或只读了半句；有没有哪一句读了两遍。
6. 如果一句也没听到：把“用什么来听”改成“内置语音”，再按一次“听一段示例”。这次应该由电脑自带的语音读出来。
7. 请告诉我们用“我的读屏软件”时是不是完全没有声音。如果是，后面的检查请一直用“内置语音”来做，并在回复里说明。

### 检查 2：在哔哩哔哩视频上开始口述

这一项用测试视频一：一个有对白、有停顿的哔哩哔哩短视频。链接由我们单独发给你。

1. 打开测试视频一的链接。
2. 让视频开始播放。页面打开后一般会自动播放；没有的话，按 Tab 键把焦点移到播放器上，按空格。
3. 视频播放几秒后，可能会听到一句提示，说这个视频还没有口述、按 Alt+Shift+D 开始。这句提示只说一次。
4. 按 Alt+Shift+D。
5. 应该听到两句话：一句是“以下为 AI 生成的口述影像。”，另一句以“SceneVoice 开始边看边生成口述”开头。
6. 继续播放。大约 20 秒之内，应该听到第一条口述，说的是画面上的内容。口述会比画面晚几秒，这是正常的。
7. 请记下：按下 Alt+Shift+D 后听到的原话；第一条口述过了多久才出现；口述是不是中文。
8. 如果听到的是“SceneVoice 在这个网站上需要通义千问 API Key”，说明密钥没有保存成功，请回到第四节。

### 检查 3：播放过程中的口述，有没有两个声音同时说

1. 接着检查 2，继续听两三分钟，不用按键。
2. 请留意：口述是在没人说话的空隙里读的，还是压着对白读的。
3. 请留意：有没有两个声音同时说话。比如读屏在读，电脑自带的语音也在读。
4. 请留意：有没有同一句话读了两遍；有没有读到一半被下一句打断。
5. 请留意：口述是不是越来越晚，离画面越来越远。
6. 按 Alt+Shift+S。应该听到对当前画面的描述。如果这一刻没有现成的描述，会先听到“正在查看……”，几秒后才是描述。
7. 按 Alt+Shift+L。应该把上一条描述再读一遍。
8. 请记下这两个键各自听到的原话，以及等了多久。

### 检查 4：Alt+Shift 快捷键和输入法

Windows 上，左边的 Alt 加 Shift 有时是“切换输入语言”的按键。我们想知道它会不会和 SceneVoice 的快捷键打架。

1. 先告诉我们：你的电脑装了几种输入语言。比如只有中文，或者中文加英语。不确定的话，按 Windows 键加空格，读屏会读出列表。
2. 先把输入法切到中文状态。
3. 在视频页上按 Alt+Shift+L，等它读完，再按一次，一共按三次。
4. 请记下：三次是不是都重复了上一条描述；读屏有没有报出“英语”“中文”“美式键盘”之类切换输入法的话。
5. 再按三次 Alt+Shift+H。这个键会把全部快捷键读一遍，比较长。
6. 想让读屏停下来，请按读屏自己的停止键，一般是 Ctrl。
7. Alt+Shift+X 停的是内置语音，并清掉 SceneVoice 还没读出的播报。读屏已经在读的那一段，它停不了。
8. 请记下：三次是不是都开始读快捷键；有没有切换输入法的播报；按 Ctrl 能不能让它停下。
9. 把输入法切到英文状态，把第 3 步到第 8 步再做一遍。
10. 做完后查一下：你的输入法还是不是原来那个。如果被切走了，请告诉我们是按哪个键的时候切走的。
11. 如果快捷键触发了读屏自己的功能，或者完全没反应，也请记下是哪个键。

如果切换输入法的问题让你没法继续，可以先这样绕开：在 Windows 设置里搜索“高级键盘设置”，进入“输入语言热键”，把“在输入语言之间”的按键顺序改成“未分配”。改不改都请告诉我们。

### 检查 5：在浏览模式和焦点模式下按键

SceneVoice 有十二个快捷键。Alt+Shift 加 D、S、L、Q 这四个由浏览器管，在哪里按都应该有效。其余八个由网页管，其中 Alt+Shift+H 是读出全部快捷键。

请在下面三种情况下各按一次 Alt+Shift+H，再各按一次 Alt+Shift+L：

1. 情况一：用上下方向键在网页里逐行浏览的时候。这是浏览模式。
2. 情况二：焦点模式。NVDA 用户按 NVDA 键加空格切换；其他读屏的用户，按 Tab 键把焦点移到播放器里的某个按钮上再试。
3. 情况三：按 Tab 键把焦点移到哔哩哔哩的弹幕输入框里的时候。

应该是这样：情况一和情况二下，两个键都有效。情况三下，Alt+Shift+L 有效，Alt+Shift+H 没有反应，因为在输入框里打字时，网页管的八个键是故意不起作用的。

请记下：三种情况下，两个键各自有没有反应，听到了什么。

### 检查 6：用中文输入法提问

1. 在视频页上按 Alt+Shift+Q。
2. 应该打开一个对话框，标题是“就当前画面提问”，焦点在“你的问题”输入框里。视频可能会暂停，这是正常的。
3. 用你平时的中文输入法输入一句话，例如：画面里有几个人。
4. 输入过程中，用空格或数字键选候选字。这时问题不应该被发出去。
5. 再试一次：输入几个拼音字母，然后按回车让字母直接上屏。这一下回车也不应该把问题发出去。
6. 整句话输入完以后，按回车。这一次才应该发出去。
7. 应该听到“正在查看视频……”，几秒后听到回答。回答的开头会说明指的是视频的哪个时间点。
8. 请记下：问题有没有在你选字的时候被提前发出去；回答有没有完整读出来；回答之前读屏有没有先读别的东西。
9. 接着在输入框里随便打几个字母，例如 q、w、e、d、f，再按几下空格。请留意：视频有没有突然播放、暂停或全屏，读屏有没有报出点赞、投币、收藏之类的提示。
10. 按 Esc 关闭对话框。NVDA 用户请注意：第一次按 Esc 可能只是退出焦点模式，要再按一次才会关闭。
11. 请记下：按了几次 Esc 才关闭；关闭后焦点回到了哪里；视频有没有继续播放。
12. 在对话框里按 Tab 键转一圈，请告诉我们焦点会不会跑到对话框外面去。

### 检查 7：弹出面板

弹出面板是从浏览器工具栏上的 SceneVoice 图标打开的小窗口。它没有快捷键，要从工具栏打开。

1. 在视频页上，按 F6 把焦点移到工具栏，可能要按几次。也可以试 Alt+Shift+T。
2. 按 Tab 键或右方向键，找到“扩展”按钮，按回车。
3. 在列表里用方向键找到 SceneVoice，按回车。
4. 请记下：能不能用键盘走到这一步；走不通的话卡在哪里。
5. 面板打开后，请记下读屏读的第一句话是什么。
6. 面板里应该有“当前视频”这一节，下面有“描述当前画面”“提问”“上一条描述有误”等按钮，再往下是设置，最后是“全部快捷键”和“全部设置”。
7. 按 Tab 键把面板走一遍。请记下：有没有哪个控件没有名字；有没有哪句话读了两遍；视频的状态有没有读出来。
8. 按 Esc 关闭面板。

### 检查 8：改变朗读速度

SceneVoice 听不到你的读屏有多快，只能按一个设定值来估算一条口述能不能放进空隙。

1. 在视频页上按 Alt+Shift+上方向键。
2. 如果你用的是“我的读屏软件”，应该听到以“读屏语速”开头的一句话，例如“读屏语速：很快。”。它改的是 SceneVoice 的估算，不会改变读屏本身的速度。
3. 如果你用的是“内置语音”，应该听到以“语速”开头的一句话，电脑语音会变快。
4. 再按 Alt+Shift+下方向键，应该调回去一档。
5. 请记下：两个键各自听到的原话；有没有触发读屏或系统自己的功能。
6. 把它调到和你读屏实际速度差不多的一档，再听一两分钟。请告诉我们：口述有没有被截断；是不是太短；是不是总赶不上画面。

### 检查 9：一直有人说话的视频

这一项用测试视频二：一个一直有人说话、几乎没有停顿的哔哩哔哩视频，例如访谈或新闻。链接由我们单独发给你。

1. 打开测试视频二的链接，播放，按 Alt+Shift+D 开始口述。
2. 听两分钟左右，不用按键。
3. 请留意：口述有没有压着人说话的声音读出来；还是一直很安静，几乎没有口述。
4. 请留意：有没有听到一句提示，说有几条描述因为没有对白空隙被跳过了。
5. 按 Alt+Shift+M。应该听到以“模式”开头的一句话，说明现在是哪种模式。再按一次会换到下一种，一共三种。
6. 一直按到听见的那句话里有“暂停视频”为止。再听一分钟。这时视频应该会自己停下来，读完一条口述，再自己继续播放。
7. 请记下：三种模式各自听到的原话；暂停模式下，视频有没有自己停、自己继续；读屏有没有把口述读完整。

## 六、测完以后

1. 请告诉我们扩展的版本号。打开设置页，按 Ctrl+End 到页面最后，那里有一个以字母 v 开头的版本号。
2. 测试密钥会由我们作废。你也可以自己删掉：在设置页的“通义千问 API Key”输入框后面，找到“删除密钥”按钮，按回车。
3. 想卸载的话：打开 edge://extensions ，找到 SceneVoice，按它的“删除”按钮。
4. 不卸载也可以。从商店安装的版本会自动更新；用办法二安装的版本不会，我们发新包时需要你重新装一次。
