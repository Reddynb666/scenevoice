# SceneVoice 声景 — YouTube 的 AI 口述影像

[English](./README.md)

SceneVoice 是一个免费、开源的浏览器扩展，为任意 YouTube 视频加上**口述影像**（无障碍解说），面向盲人和低视力观众。它用谷歌的 Gemini 模型观看视频，写出画面的简短描述，并在对白之间的空隙朗读出来——默认通过**你自己的读屏软件**，所以语音、语速和盲文显示器都是你熟悉的。

它从一开始就为读屏用户设计：所有操作都能用键盘完成，所有状态都会播报，没有任何信息只藏在图片里。

## 功能

- **按需为任意 YouTube 视频生成口述。** 在视频页按 `Alt+Shift+D`，每 5 分钟视频约需半分钟。前面的部分会先就绪，全部结果保存在本机，同一个视频只需生成一次。
- **放进对白空隙里。** 每个时刻的描述都有三种长度（简洁、标准、详细），SceneVoice 会挑能放进空隙的最长版本；连最短版本都放不下时就跳过，不压住对白。视频有字幕（包括 YouTube 自动字幕）时，会按字幕时间轴找出真实的对白空隙。你也可以让它暂停视频读完整描述，或者平时沉默、只在你要求时描述。
- **朗读画面文字。** 标题卡、视频内嵌字幕、标牌、幻灯片、聊天消息都会读出来，非目标语言的文字会附上翻译。这一项可以单独关闭。
- **描述当前画面、随时提问。** `Alt+Shift+S` 立刻描述此刻画面；`Alt+Shift+Q` 打开对话框，可以输入"谁在说话？""牌子上写的什么？"之类的问题，得到针对这一刻的回答。
- **读屏优先，也有内置语音。** 默认把描述交给 NVDA、JAWS、VoiceOver 等读屏软件的实时区域朗读；不用读屏的人可以切换到浏览器内置语音。
- **中英文及更多语言。** 口述可用简体中文、繁体中文、英文、西班牙文、法文、德文、葡萄牙文、日文、韩文、俄文、阿拉伯文、印地文。界面有简体中文和英文。
- **大字幕叠加层**，方便低视力用户和陪你一起看的人。
- **无账号、无服务器、不追踪。** 你使用自己的免费 Gemini API 密钥，SceneVoice 没有后端，不收集任何数据。

## 安装

### Chrome 应用商店

即将上架。在此之前请按下面的方式安装。支持 Chrome、Edge、Brave 等 Chromium 内核浏览器（116 及以上版本）。

### 开发者模式安装

1. 从 Releases 页面下载最新的 `scenevoice-<版本>.zip` 并解压，或自行构建（见"开发"）。
2. 打开 `chrome://extensions`，开启右上角的**开发者模式**，点击**加载已解压的扩展程序**，选择解压后的 `dist` 文件夹。
3. 设置页会自动打开，按页面上的三步添加 Gemini API 密钥。

### 获取 Gemini API 密钥

1. 打开 [aistudio.google.com/apikey](https://aistudio.google.com/apikey)，用谷歌账号登录。
2. 点击 **Create API key**（创建 API 密钥）并复制。
3. 粘贴到 SceneVoice 设置页，按**保存并测试**。

免费额度足够日常使用。发送给 Gemini 的内容适用谷歌的 Gemini API 条款，详见下方"隐私"。

在中国内地直接访问谷歌服务可能受限。设置页的"高级"里可以填写兼容的中转地址，但请注意：中转服务能看到你的密钥和请求内容。

## 使用

打开任意 YouTube 视频。

| 操作 | 快捷键 |
| --- | --- |
| 为这个视频生成口述，或开启/关闭口述 | `Alt+Shift+D` |
| 描述此刻画面 | `Alt+Shift+S` |
| 重复上一条描述 | `Alt+Shift+L` |
| 就当前画面提问 | `Alt+Shift+Q` |
| 切换详细程度 | （自行设置） |
| 切换"描述放不下时"的模式 | （自行设置） |
| 切换口述多少 | （自行设置） |
| 加快语速 | （自行设置） |
| 放慢语速 | （自行设置） |
| 停止朗读 | （自行设置） |

快捷键可在 `chrome://extensions/shortcuts` 修改，如果和读屏软件冲突请改掉。Chrome 只允许一个扩展预设四个快捷键，其余的默认没有按键；设置页会把它们全部列出来，并有按钮直接打开 Chrome 的快捷键页面。播放器控制栏里的 SceneVoice 按钮和工具栏弹出面板可以用鼠标完成同样的操作。

用快捷键切换设置时，会读出新的值，例如"详细程度：简洁。""语速：1.4 倍。"。*加快语速*、*放慢语速*调的是内置语音的语速；使用读屏软件时，调的是 SceneVoice 估算用的读屏语速（见下方设置），不会改变读屏软件本身。

第一次播放没有口述的视频时，SceneVoice 会提示一次，并告诉你快捷键。

### 值得了解的设置

- **描述放不进对白空隙时** —— *不暂停*（默认）：换用放得下的较短版本，仍放不下就跳过；*暂停视频*：读完整描述后继续播放；*只在我要求时*：平时沉默，按"描述此刻画面"才说。
- **详细程度** —— 简洁、标准、详细：每一条描述有多长。"标准"接近专业口述影像的写法。
- **按视频类型自动调整** —— 默认开启。娱乐类（影视、音乐、Vlog、游戏）不暂停、简短口述，不打断节奏；教程讲解类（教学、操作演示、科普、新闻图表）会暂停并详细口述，屏幕上的关键信息不会漏掉。每种类型用什么模式和详细程度，可以在设置页修改。类型根据视频在 YouTube 上的分类和标题判断（从页面读取，不额外发请求），生成口述后以 Gemini 的判断为准（它在返回口述的同一次回答里顺带给出类型）。每个视频切换时会播报一次改了什么，第一次还会告诉你怎么改回来；弹出面板显示当前视频实际使用的模式和详细程度。你自己选过的模式或详细程度（在弹出面板、设置页或用快捷键）始终优先；设置页的"重新按视频类型调整"可以撤销这一点。
- **口述多少** —— 只说关键（场景切换、谁在场、主要动作、重要文字）、标准（再加表情、手势、物品、外貌）、全部（连景物和背景也说，接近广播剧式的无障碍电影）。模型一次把所有内容都写好，这个设置只是筛选，切换立即生效。
- **你的读屏软件语速有多快？** —— SceneVoice 听不到读屏的声音，只能靠这个设置判断描述能否放进空隙。如果描述经常被截断，选慢一档；如果太短，选快一档。
- **打断读屏的其他朗读** —— 让描述与画面同步，代价是会打断读屏正在读的内容。默认关闭。
- **自动生成口述** —— 一打开视频就开始生成。默认关闭，因为每打开一个视频都会消耗 API 额度。
- **内置语音** —— 语音、语速、音调分别可调，"试听"会用口述语言读一句示例。列表先列出适合当前口述语言的语音（中文口述就先列中文语音），每种口述语言各自记住选过的语音。在别的电脑上选的语音如果这台电脑没有，会自动换用合适的语音。
- **弹出面板里的快速设置** —— 详细程度、模式和语速（内置语音的语速，或读屏语速）在工具栏弹出面板里就能调，不必进设置页。
- **恢复默认设置** —— 在设置页最后。所有偏好恢复为初始值，API 密钥、模型、已保存的口述和快捷键都保留。

除密钥外的设置保存在浏览器的个人资料里（`chrome.storage.sync`），开启同步后会跟着你到其他浏览器。

## 工作原理

```
YouTube 页面 ──（视频链接、标题）──▶ Gemini API（你的密钥）──（带时间戳的 JSON 脚本）──▶ 保存在本机
                                                                                          │
                                          播放进度 ──▶ 调度器 ──▶ 选择长度 ──▶ 你的读屏软件 / 内置语音
```

- 视频本身不会被下载或上传。Gemini 通过链接读取公开的 YouTube 视频，每次处理 5 分钟。请求在扩展自己的隐藏页面（offscreen document）里的 worker 中发出，不经过 YouTube 页面：密钥不会进入页面，YouTube 的页面策略拦不住请求，离开视频后生成也会继续。每段完成就保存进度，中断最多损失一段；两个标签页打开同一视频时只生成一次。
- 选中的模型过载或密钥已不能使用它时，扩展会逐步加长间隔重试，仍不行就自动换下一个最合适的模型继续。
- 模型为每个时刻写出三种长度的描述、后面空隙有多长、是画面动作还是画面文字、重要程度。
- 视频有字幕时，扩展会读取字幕的时间轴（在页面内直接向 YouTube 获取，不发往别处），用来校正模型估计的空隙。如果描述刚好落在一句话快说完的时候，会顺延到这句话说完。
- 观看时，扩展每秒多次检查播放位置。到了某条描述的时间，就按你的读屏语速和播放倍速选择能放进空隙的最长版本（都放不下就跳过；暂停模式下则暂停视频再读），稍微压低视频音量，把文字交给实时区域（或内置语音）。
- 前一段里出现的人物会传给下一段，保证称呼一致。

描述由大模型生成，可能出错。SceneVoice 要求模型在不确定时说"看起来像"，不编造人名，但涉及安全的内容请自行核实。

## 隐私

- SceneVoice 没有服务器，不需要账号，不发送任何统计数据。
- 生成口述时，视频地址、标题和简介会连同你的 API 密钥发送给 Gemini API，适用谷歌的 [Gemini API 条款](https://ai.google.dev/gemini-api/terms)。
- 密钥只保存在本机（`chrome.storage.local`），只发送到设置页显示的 Gemini API 地址，不会出现在网址里。
- 口述保存在本机，同一视频只需生成一次；可在设置页一键全部删除。
- 设置项（不含密钥）会随浏览器账号同步。

完整说明见 [PRIVACY.md](./PRIVACY.md)。

## 开发

```
npm install
npm run build        # 构建到 dist/
npm test             # 单元测试（vitest）
npm run test:e2e     # 在无头 Chromium 里用模拟 Gemini 服务跑端到端测试
npm run package      # 构建并打包成 scenevoice-<版本>.zip
npm run dev          # 修改后自动重新构建
```

目录结构：

- `src/content/` —— 运行在 YouTube 页面：跟踪播放、实时区域、播放器按钮、提问对话框，以及 `generator.js`：页面这一侧的生成接口（启动、停止、提问；进度以消息形式送回）。
- `src/background/` —— 后台 Service Worker：语音合成、快捷键、给弹出面板的状态、缓存管理，以及生成任务的枢纽（启动任务、保存每段结果、通知各标签页）。它自己不调用 Gemini：Chrome 会终止 fetch 超过 30 秒还没响应的 Service Worker，而视频请求经常超过 30 秒。
- `src/offscreen/` —— 隐藏页面及其 web worker，Gemini 请求真正在这里发出（`worker.js` 维护任务列表，`offscreen.js` 负责和 Service Worker 之间的消息）。
- `src/shared/` —— 各部分共用的逻辑：Gemini 客户端和提示词、生成循环（`generation.js`：分段、续传、模型回退）、脚本解析、调度、缓存、设置。
- `src/popup/`、`src/options/` —— 工具栏弹出面板和设置页。
- `scripts/locales.mjs` —— 全部界面文字的中英文；构建时生成 `_locales/`。
- `test/` —— 单元测试，以及 `test/e2e/e2e.py`：在无头 Chromium 里驱动真实扩展，对接假 YouTube 页面和模拟 Gemini API（127 项检查，含 axe 无障碍扫描）。

发布前用读屏软件测试的清单见 [CONTRIBUTING.md](./CONTRIBUTING.md)。

## 路线图

- 可编辑的角色记忆（"把穿红大衣的女人叫作 Maya"），按频道保存。
- 按视频类型给默认值（教程更详细，音乐视频更简洁）。
- 共享人工修正过的口述，一个视频只需描述一次。
- 支持其他能用链接访问视频的平台。
