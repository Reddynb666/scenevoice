# SceneVoice 声景 — YouTube 的 AI 口述影像

[English](./README.md)

SceneVoice 是一个免费、开源的浏览器扩展，为任意 YouTube 视频加上**口述影像**（无障碍解说），面向盲人和低视力观众。它用谷歌的 Gemini 模型观看视频，写出画面的简短描述，并在对白之间的空隙朗读出来——默认通过**你自己的读屏软件**，所以语音、语速和盲文显示器都是你熟悉的。

它从一开始就为读屏用户设计：所有操作都能用键盘完成，所有状态都会播报，没有任何信息只藏在图片里。

## 功能

- **按需为任意 YouTube 视频生成口述。** 在视频页按 `Alt+Shift+D`，每 5 分钟视频约需半分钟。前面的部分会先就绪（会听到“可以开始看了”），进度显示在播放器控制条上方，并在 25%、50%、75% 时播报（可在设置里关闭），全部结果保存在本机，同一个视频只需生成一次。
- **放进对白空隙里。** 每个时刻的描述都有三种长度（简洁、标准、详细），SceneVoice 会挑能放进空隙的最长版本；连最短版本都放不下时就跳过，不压住对白。视频有字幕（包括 YouTube 自动字幕）时，会按字幕时间轴找出真实的对白空隙。你也可以让它暂停视频读完整描述，或者平时沉默、只在你要求时描述。
- **屏幕文字优先、按原文朗读。** 标题、人名条、幻灯片、图表数字、价格、电话和地址、代码、菜单、标牌、聊天消息都会照原样转写，先于其他描述读出；非目标语言的文字读原文并附翻译。已经听得到的文字（讲者念出的幻灯片、与字幕一致的内嵌字幕）不再重复。这一项可以单独关闭。
- **安静时刻留白。** 不会为了填满空隙硬加描述。音乐、风景、长镜头只在画面真正变化时简短说一句。
- **描述当前画面、随时提问。** `Alt+Shift+S` 立刻描述此刻画面；`Alt+Shift+Q` 打开对话框，可以输入"谁在说话？""牌子上写的什么？"之类的问题，得到针对这一刻的回答。每个回答都先说明指的是哪个时间点（"在 2:15 处：……"），下面的"跳到 2:15"按钮可以直接跳过去。
- **只说看得见的，没把握就直说。** 描述只讲画面上能看到的：不猜人物的情绪和动机，不做评价，屏幕上或对白里没出现名字就不点名。画面模糊、太小或一闪而过时会明说（"可能""看不清"），Gemini 没把握的描述也会少播一些。
- **说错了可以纠正。** 在弹出面板点"上一条描述有误"（也可以自己设快捷键），就会标记刚听到的那条描述，只重新生成这一段、替换保存的口述，每一步都会播报。标记记录只保存在本机。
- **读屏优先，也有内置语音。** 默认把描述交给 NVDA、JAWS、VoiceOver 等读屏软件的实时区域朗读；不用读屏的人可以切换到浏览器内置语音。
- **用你的语言。** 口述可以用浏览器设置的任何语言；其中 24 种（简体中文、繁体中文、英文、西班牙文、法文、德文、葡萄牙文、日文、韩文、俄文、阿拉伯文、印地文、意大利文、荷兰文、波兰文、土耳其文、越南文、泰文、印尼文、孟加拉文、乌尔都文、波斯文、乌克兰文、斯瓦希里文）各有自己的不确定措辞和试听句。界面有 14 种语言：简体中文和英文完整并经过校对；繁体中文、西班牙文、巴西葡萄牙文、法文、德文、日文、韩文、俄文、阿拉伯文、印地文、印尼文、越南文为 AI 初稿，等待使用读屏的母语者校对（见 `CONTRIBUTING.md`）。
- **大字幕叠加层**，方便低视力用户和陪你一起看的人。
- **无账号、不追踪。** 用自己的免费 Gemini API 密钥时，SceneVoice 没有服务器，不收集任何数据；可选的 SceneVoice 云端中转（“免费开始”）见下文[隐私](#隐私)。
- **中国站（实验性）：B 站 + 通义千问。** 在 B 站视频页上，可以用阿里云的通义千问边看边生成口述，见[下文](#中国站--b-站实验性)。

## 安装

支持 Chrome、Edge、Brave 等 Chromium 内核浏览器（116 及以上版本）。可从以下渠道获取：

- Chrome 应用商店（上架后附链接）
- Edge 加载项商店（上架后附链接）
- [GitHub Releases](https://github.com/reddynb666/scenevoice/releases)：`scenevoice-<版本>.zip`，附 `SHA256SUMS` 用于校验下载；以“加载已解压的扩展程序”方式安装（见[开发](#开发)）
- 面向中国内地的 Gitee 镜像（见 [docs/distribution-china.md](./docs/distribution-china.md)）

### 不安装也能试

[网页播放器](https://reddynb666.github.io/scenevoice/play/?lang=zh-CN)（英文版：[play/](https://reddynb666.github.io/scenevoice/play/)）接收一个 YouTube 链接，直接在浏览器里通过你的读屏软件或浏览器的语音读出 AI 口述影像，用你自己的 Gemini 密钥（到 Google AI Studio 免费申请；页面上也有 SceneVoice 云端的选项，但尚未开放）。手机上也能用。和扩展的区别：只支持 YouTube（粘贴 B 站链接会被拒绝，并提示改用扩展）；没有字幕掐时间（空隙是模型估计的）；不按视频类型自动调整；YouTube 播放器从 youtube-nocookie.com 嵌入，并且不在 Tab 顺序里，由页面自己的按钮和按键来控制。在播放器区域里：空格播放或暂停，D 描述当前画面，R 重复，A 提问，S 停止朗读，左右方向键前后跳 5 秒，上下方向键调整朗读速度，M 切换模式，问号读出按键列表；`Alt+Shift+D`、`S`、`L`、`Q` 在页面任何位置都有效，和扩展里的字母一样。

### 首次使用

安装后会打开欢迎页：先听一段示例，再选择 SceneVoice 云端（有免费额度，不用 Key）或自己的 Key。

1. **先听听看。** 三条示例口述，通过你的读屏软件或内置语音朗读，不会发送任何内容。
2. **选择口述由谁生成。** *自己的 Key*（目前可用的路径）：设置页会在 Key 输入框打开（中文浏览器下在通义千问 Key 输入框），并附有适合读屏用户的分步申请指南。Key 不能用时会说明原因：Key 错误、没网、额度用完，或所在地区不能使用 Gemini。*SceneVoice 云端*还没有开放：中转尚未部署，按“免费开始”会直接说明，并引导你改用自己的 Key。开放之后，按“免费开始”会得到一个匿名的设备凭证，每天可以新生成 60 分钟视频的口述；其他用户已经描述过的视频不计入，生成完成的口述会以文字形式分享回缓存（可在设置里关闭）。
3. **试一试。** 页面会说出你的快捷键、提醒在视频页按 `Alt+Shift+H` 可以听到全部按键，并给出一个短视频的链接。第一次播放还没有口述的视频时，SceneVoice 会提示一次怎样开始。弹出面板的“全部快捷键”列出了所有快捷键，并有按钮直接打开修改它们的设置区域。

### 获取 Gemini API 密钥

1. 打开 [aistudio.google.com/apikey](https://aistudio.google.com/apikey)，用谷歌账号登录。
2. 点击 **Create API key**（创建 API 密钥）并复制。
3. 粘贴到 SceneVoice 设置页，按**保存并测试**。

免费额度足够日常使用。发送给 Gemini 的内容适用谷歌的 Gemini API 条款，详见下方"隐私"。

在中国内地直接访问谷歌服务可能受限。设置页的"高级"里可以填写兼容的中转地址，但请注意：中转服务能看到你的密钥和请求内容。

## 使用

打开任意 YouTube 视频。

### 快捷键

| 操作 | 快捷键 | 在哪里修改 |
| --- | --- | --- |
| 为这个视频生成口述，或开启/关闭口述 | `Alt+Shift+D` | `chrome://extensions/shortcuts` |
| 描述此刻画面 | `Alt+Shift+S` | `chrome://extensions/shortcuts` |
| 重复上一条描述 | `Alt+Shift+L` | `chrome://extensions/shortcuts` |
| 就当前画面提问 | `Alt+Shift+Q` | `chrome://extensions/shortcuts` |
| 标记上一条描述有误，并重新生成这一段 | `Alt+Shift+W` | SceneVoice 设置页“快捷键” |
| 切换详细程度 | `Alt+Shift+E` | SceneVoice 设置页“快捷键” |
| 切换模式（描述放不下时怎么办） | `Alt+Shift+M` | SceneVoice 设置页“快捷键” |
| 切换描述密度 | `Alt+Shift+N` | SceneVoice 设置页“快捷键” |
| 加快语速 | `Alt+Shift+Up`（上方向键） | SceneVoice 设置页“快捷键” |
| 放慢语速 | `Alt+Shift+Down`（下方向键） | SceneVoice 设置页“快捷键” |
| 停止朗读 | `Alt+Shift+X` | SceneVoice 设置页“快捷键” |
| 读出全部快捷键 | `Alt+Shift+H` | SceneVoice 设置页“快捷键” |

在 Mac 上，`Alt` 就是 Option 键，SceneVoice 会把按键读成“Option+Shift+……”。随时按 `Alt+Shift+H`，就能听到整个列表和当前设置的按键。

Chrome 只允许一个扩展预设四个快捷键，所以其余八个由 SceneVoice 自己在视频页上处理。修改它们到设置页的“快捷键”部分：按“修改”，再按新的组合键（按 Escape 保留原来的）；“清除”去掉按键；“恢复默认快捷键”全部复原。页面会说出保存了什么；已经被另一个 SceneVoice 命令或 Chrome 的四个快捷键占用的按键会被拒绝；组合键必须带 Alt、Ctrl 或 Command，再加一个字母、数字、方向键或功能键。Chrome 保留的那四个仍然在 `chrome://extensions/shortcuts` 修改，设置页有按钮直接打开它。如果某个按键和读屏软件冲突，请改掉。在输入框、评论框、搜索框或提问对话框里打字时，页面快捷键不起作用；由 SceneVoice 处理的按键不会再传给播放器。播放器控制栏里的 SceneVoice 按钮和工具栏弹出面板可以用鼠标完成同样的操作。

用快捷键切换设置时，会读出新的值，例如"详细程度：简洁。""语速：1.4 倍。"。*加快语速*、*放慢语速*调的是内置语音的语速；使用读屏软件时，调的是 SceneVoice 估算用的读屏语速（见下方设置），不会改变读屏软件本身。

第一次播放没有口述的视频时，SceneVoice 会提示一次，并告诉你快捷键。

### 描述有误时

听到一条你觉得不对的描述后，在弹出面板点"上一条描述有误"，或按你设的快捷键。SceneVoice 会先说明标记了哪一条（"已标记 1:35 处的描述有误，正在重新生成这一段。原描述：……"），然后只让 Gemini 重新看这一刻前后约 20 秒的画面，再读出新的描述（"已更新。1:35 处的描述现在是：……"）。如果重新看过后发现这一刻没有需要描述的内容，就删除这条描述并告诉你。视频的其他部分不会重新生成。

如果还没听到过描述，标记的是当前画面对应的那一条。提问的回答不会保存，所以没有可以标记的内容，重新提问即可。在"查看全部口述"页面上，更正过的描述会标出"已更正"。

你标记过哪些描述只记录在本机，和已保存的口述放在一起，删除口述时一并删除。重新生成时，会把你标记的那条描述发给 Gemini，免得它照原样再说一遍。

### 值得了解的设置

- **描述放不进对白空隙时** —— *不暂停*（默认）：换用放得下的较短版本，仍放不下就跳过；*暂停视频*：读完整描述后继续播放；*只在我要求时*：平时沉默，按"描述此刻画面"才说。
- **详细程度** —— 简洁、标准、详细：每一条描述有多长。"标准"接近专业口述影像的写法。
- **描述密度** —— 仅关键（场景切换、谁在场、主要动作）、适中（默认，再加表情、手势、物品、外貌）、尽量多（连景物和背景也说）。屏幕文字多放宽一档：“仅关键”也会读有用的屏幕文字，“适中”读全部屏幕文字。无论哪一档都不会为了填满空隙硬加描述。模型一次把所有内容都写好，这个设置只是筛选，切换立即生效。
- **朗读屏幕文字** —— 默认开启。屏幕文字按原文转写，优先于其他描述：正在读屏幕文字时，到点的画面描述（除非更重要）会被跳过，不会打断它；文字出现时如果有人正在说话，最多等 8 秒找一个空隙再读。字幕显示对白里已经说出的文字不再朗读。
- **按视频类型自动调整** —— 默认开启。娱乐类（影视、音乐、Vlog、游戏）不暂停、简短口述、只说关键，不打断节奏，安静的段落也不打扰；教程讲解类（教学、操作演示、科普、新闻图表）会暂停并详细口述，屏幕上的信息不会漏掉。每种类型用什么模式、详细程度和描述密度，可以在设置页修改。类型根据视频在 YouTube 上的分类和标题判断（从页面读取，不额外发请求），生成口述后以 Gemini 的判断为准（它在返回口述的同一次回答里顺带给出类型）。每个视频切换时会播报一次改了什么，第一次还会告诉你怎么改回来；弹出面板显示当前视频实际使用的设置。你自己选过的模式、详细程度或描述密度（在弹出面板、设置页或用快捷键）始终优先；设置页的"重新按视频类型调整"可以撤销这一点。
- **你的读屏软件语速有多快？** —— SceneVoice 听不到读屏的声音，只能靠这个设置判断描述能否放进空隙。如果描述经常被截断，选慢一档；如果太短，选快一档。
- **打断读屏的其他朗读** —— 让描述与画面同步，代价是会打断读屏正在读的内容。默认关闭。
- **自动生成口述** —— 一打开视频就开始生成。默认关闭，因为每打开一个视频都会消耗 API 额度。
- **内置语音** —— 语音、语速、音调分别可调，"试听"会用口述语言读一句示例。列表先列出适合当前口述语言的语音（中文口述就先列中文语音），每种口述语言各自记住选过的语音。在别的电脑上选的语音如果这台电脑没有，会自动换用合适的语音。
- **弹出面板里的快速设置** —— 详细程度、模式、描述密度、屏幕文字开关和语速（内置语音的语速，或读屏语速）在工具栏弹出面板里就能调，不必进设置页。
- **恢复默认设置** —— 在设置页最后。所有偏好恢复为初始值，API 密钥、模型和已保存的口述保留。由 SceneVoice 在页面上处理的快捷键也会恢复默认；Chrome 保留的那四个不受影响。

除密钥外的设置保存在浏览器的个人资料里（`chrome.storage.sync`），开启同步后会跟着你到其他浏览器。

## 中国站 / B 站（实验性）

在中国内地通常无法访问 YouTube 和 Gemini。这个原型让 SceneVoice 在 B 站视频页（`www.bilibili.com/video/…`）上配合阿里云的通义千问使用。它是供测试的最小可用版本，还不是正式发布。

### 设置

1. 在阿里云百炼控制台创建 API Key：[bailian.console.aliyun.com](https://bailian.console.aliyun.com/)。模型需要能看懂图片，默认是 `qwen3-vl-plus`。设置页里链接的分步申请指南有详细步骤。
2. 在 SceneVoice 设置页“1. 连接 AI 模型”→“通义千问（阿里云百炼）”里粘贴密钥，按**保存并测试**。这个密钥和 Gemini 密钥一样受保护：只存在本机，网页和内容脚本读不到，只发送到通义千问 API 地址。
3. “各网站用哪个模型”：默认 B 站用通义千问，YouTube 用 Gemini。两个网站都可以任选其一。
4. 打开一个 B 站视频，按 `Alt+Shift+D`（或在弹出面板点“生成口述”）。

### 和 YouTube + Gemini 的区别

- Gemini 通过链接打开 YouTube 视频，在你看到之前就把口述写好。通义千问不能打开视频链接，Gemini 也打不开 B 站的链接，所以在 B 站上（以及在 YouTube 上选用通义千问时），SceneVoice 改为**边看边描述**：每 2 秒在页面里用 canvas 截取一张正在播放的 `<video>` 画面（缩小到 640 像素宽的 JPEG），每 12 秒把其中最多 6 张发给模型。最新的一条重要描述会在下一个放得下的对白空隙里读出，所以会**比画面晚几秒**。所有描述都会保存，下次观看时会像 YouTube 一样按时播报。只有你看过的部分才会有口述。
- 边看边描述时，播放器控制条上方会显示“正在边看边生成”和“已描述到 1:35”（你正在看的这部分描述到了哪里），以及整个视频已描述的比例。弹出面板里也会显示；视频描述到 25%、50%、75% 时会播报（开启“播报生成进度”时）。
- “描述当前画面”、提问和“上一条描述有误”会发送那一刻的画面。
- 口述会标明由 AI 生成：一个视频开始口述时会先说“以下为 AI 生成的口述影像”（可在设置里改为每个视频只说第一次），视频上显示的口述文字标有“AI 口述”。这是《人工智能生成合成内容标识办法》（2025 年 9 月 1 日起施行）的要求。
- 你在 B 站播放器里打开 CC 字幕后，SceneVoice 会用播放器自己加载的那个字幕文件，像 YouTube 字幕一样校正对白空隙；没打开字幕或没有字幕时，退回模型自己的估计。SceneVoice 不调用 B 站的任何接口，标题、UP 主、简介和分区都读自页面本身。
- 视频类型（娱乐类或教程讲解类）根据 B 站分区和标题判断。
- 在 B 站上，口述语言选“与浏览器语言相同”时一律用中文；用内置语音时，优先列出并使用中文语音。读屏输出和 YouTube 上一样。
- `Alt+Shift+D` 可以开关口述（同时开关截图）。弹出面板里的“停止”会停止截图，已生成的口述保留。

中国内地的上架与分发（Edge 加载项商店、Gitee 镜像）：见 [docs/distribution-china.md](docs/distribution-china.md)。

### 已知限制

- **浏览器保护的画面（跨域）。** 如果视频是从其他网站加载、且对方没有允许跨域（CORS），浏览器会把 canvas 标记为“被污染”，不让网页读取画面。这时 SceneVoice 会明确告诉你截不到这个视频的画面、无法为它生成口述，并且不发送任何内容。有些 B 站视频可能用 B 站自己的 `<bwp-video>` 元素播放而不是 `<video>`，它无法画到 canvas 上，也会给出类似提示。
- **受版权保护（DRM）的视频。** 付费或会员视频常常是加密的，浏览器会把它画成纯黑画面，而且不报错。连续约 12 秒都是黑屏时，SceneVoice 会停止截图，并告诉你这个视频受保护。（影片里的黑场一般短得多。）
- 第一次观看时口述会晚几秒，跳过的部分没有口述。模型只看到静止画面，画面之间的动作和所有声音它都不知道。
- 费用：每分钟视频约 5 次请求，每次最多 6 张小图，费用记在你的阿里云账号上。按 qwen3-vl-plus 2026 年 10 月的价格，每小时视频大约 2 元（估算，设置页也写明了）。
- B 站的页面结构和网页接口没有公开文档，随时可能变化。未登录时可能拿不到字幕。暂不支持番剧、直播、嵌在其他网站里的播放器和移动版网页。
- B 站内容脚本还没有在真实网站上用读屏软件试过（见下方的人工检查）。

## 工作原理

```
YouTube 页面 ──（视频链接、标题）──▶ Gemini API（你的密钥）──（带时间戳的 JSON 脚本）──▶ 保存在本机
                                                                                          │
                                          播放进度 ──▶ 调度器 ──▶ 选择长度 ──▶ 你的读屏软件 / 内置语音
```

- 视频本身不会被下载或上传。Gemini 通过链接读取公开的 YouTube 视频，每次处理 5 分钟。请求在扩展自己的隐藏页面（offscreen document）里的 worker 中发出，不经过 YouTube 页面：密钥不会进入页面，YouTube 的页面策略拦不住请求，离开视频后生成也会继续。每段完成就保存进度，中断最多损失一段；两个标签页打开同一视频时只生成一次。
- 使用 SceneVoice 云端时，同样的请求改为发往项目的中转（`api.scenevoice.app`），携带匿名设备凭证而不是密钥，由中转用项目自己的密钥调用 Gemini；其余一切不变。
- 选中的模型过载或密钥已不能使用它时，扩展会逐步加长间隔重试，仍不行就自动换下一个最合适的模型继续。
- 模型为每个时刻写出三种长度的描述、后面空隙有多长、是画面动作还是屏幕文字、重要程度。屏幕文字还会单独给出逐字转写，并且先转写再写朗读版本，让朗读版本照原文引用而不是意译；描述翻译或缩短了原文时，口述文本页会显示原文。
- 视频有字幕时，扩展会读取字幕（在页面内直接向 YouTube 获取，不发往别处）。字幕的时间轴用来校正模型估计的空隙：如果描述刚好落在一句话快说完的时候，会顺延到这句话说完。字幕的内容用来去重：前后几秒内对白里已经说出的屏幕文字不再朗读。
- 观看时，扩展每秒多次检查播放位置。到了某条描述的时间，就按你的读屏语速和播放倍速选择能放进空隙的最长版本（都放不下就跳过；暂停模式下则暂停视频再读），稍微压低视频音量，把文字交给实时区域（或内置语音）。
- 前一段里出现的人物会传给下一段，保证称呼一致。

描述由大模型生成，可能出错。SceneVoice 要求模型只描述看得见的东西（不猜情绪动机、不评价、不推测身份，并给出中英文的正反例），不确定时说"可能""看不清"，还要为每条描述给出把握程度。没把握的描述重要性降一级、播得更少；如果它自己的措辞没有说明，还会在前面加上"不太确定。"。提问的回答会说明指的是哪个时间点，画面上看不出答案时会直说。发现错误可以标记纠正（见上文）。尽管如此，涉及安全的内容请自行核实。

## 隐私

- 用自己的密钥时，SceneVoice 没有服务器，不需要账号，不发送任何统计数据。唯一的例外是下文可选的 SceneVoice 云端中转。
- 生成口述时，视频地址、标题和简介会连同你的 API 密钥发送给 Gemini API；重新生成某一段时，还会发送你标记有误的那条描述。适用谷歌的 [Gemini API 条款](https://ai.google.dev/gemini-api/terms)。
- 密钥只保存在本机（`chrome.storage.local`），只发送到设置页显示的 Gemini API 地址，不会出现在网址里。
- 口述保存在本机，同一视频只需生成一次；可在设置页一键全部删除。
- 你标记有误的描述只记录在本机，和已保存的口述放在一起，删除口述时一并删除。没有收集反馈的服务器。
- 设置项（不含密钥）会随浏览器账号同步。
- **SceneVoice 云端**（可选；按“免费开始”之前是关闭的）：请求发往项目的中转 `api.scenevoice.app`，携带匿名设备凭证而不是密钥，由中转用项目自己的密钥调用 Gemini。中转按凭证只保存今天描述了多少秒视频、所在档位和已激活的许可证密钥；不保存画面、问题、回答或你的 IP 地址，也不记录请求。“免费开始”同时会开启“共享已完成的口述”：一个视频的口述全部生成后，其文字（绝不包括画面、问题或你的密钥）会发送给中转，让下一位听同一个视频的人直接使用；可在设置里关闭。“停止使用云端”会删除凭证。
- 用量统计（当天每个模型的请求数、token 数和大致费用，以及每个视频的 token 数）和你设置的每日上限只保存在本机，绝不发送到任何地方。
- 网页播放器发给 Gemini API（或用云端时发给中转）的内容相同；密钥只放在标签页的会话存储里，除非你勾选“在这台设备上记住密钥”；没有统计分析；YouTube 播放器从 youtube-nocookie.com 嵌入，它仍会设置 YouTube 自己的 Cookie。详见隐私说明的“网页播放器”一节。

完整说明见 [PRIVACY.zh-CN.md](./PRIVACY.zh-CN.md)（英文原文：[PRIVACY.md](./PRIVACY.md)）。

## 开发

```
npm install
npm run build        # 构建到 dist/
npm test             # 单元测试（vitest）
npm run test:e2e     # 在无头 Chromium 里用模拟 Gemini 服务跑端到端测试
npm run package      # 构建并打包成 scenevoice-<版本>.zip（给商店）和 -sourcemaps.zip
npm run build:meta   # 构建并生成 dist-meta.json 与各包体积表（content.js 超过 120 KB 时 CI 失败）
npm run screenshots  # 生成商店截图和宣传图到 docs/store/（需要先有 dist/）
npm run release -- 1.2.0   # 切 CHANGELOG、设版本号、测试、构建、提交并打 tag（不推送）；见 docs/release.md
npm run dev          # 修改后自动重新构建
npm run build:web    # 网页播放器的包 site/play/player.js（不进 git；Pages 工作流会自己构建）
node site/check.mjs  # 网站无障碍检查，包括网页播放器页面
```

开发者模式安装：

1. 自行构建（`npm run build`），或从 [Releases](https://github.com/reddynb666/scenevoice/releases) 下载 `scenevoice-<版本>.zip` 并解压到一个以后不会删除的文件夹。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启右上角的**开发者模式**，点击**加载已解压的扩展程序**，选择 `dist` 文件夹（或解压出的文件夹）。
3. 每次 `npm run build` 之后，在该页面点“重新加载”，再刷新视频标签页。

目录结构：

- `src/content/` —— 运行在 YouTube 页面和 B 站视频页：跟踪播放、实时区域、播放器按钮、提问对话框，以及 `generator.js`：页面这一侧的生成接口（启动、停止、提问；进度以消息形式送回）。和网站有关的部分在平台适配器 `youtube.js`、`bilibili.js` 里（由 `platforms.js` 选择）；`frames.js` 为需要发送画面的模型截取播放中的视频画面。
- `src/background/` —— 后台 Service Worker：语音合成、快捷键、给弹出面板的状态、缓存管理，以及生成任务的枢纽（启动任务、保存每段结果、通知各标签页）。它自己不调用 Gemini：Chrome 会终止 fetch 超过 30 秒还没响应的 Service Worker，而视频请求经常超过 30 秒。
- `src/offscreen/` —— 隐藏页面及其 web worker，模型请求真正在这里发出：Gemini、通义千问，或 SceneVoice Cloud 的中转（包括它的共享缓存读写）（`worker.js` 维护任务列表，`offscreen.js` 负责和 Service Worker 之间的消息）。
- `src/shared/` —— 各部分共用的逻辑：Gemini 客户端和提示词、生成循环（`generation.js`：分段、续传、模型回退）、脚本解析、缓存、设置。每个网站用哪个模型（Gemini、通义千问还是 SceneVoice Cloud）、模型是打开视频链接还是接收画面，在 `providers.js` 里；`qwen.js` 是通义千问客户端，`cloud.js` 是中转自身的接口（设备令牌、额度、许可证，以及脚本哪些部分可以共享），`usage.js` 是每日计数、价格和每日上限，`language.js` 决定哪些语言代码可以作为口述语言，`scheduler.js` 决定什么可以打断什么，`frames.js` 是基于画面的提示词，`describe.js` 用任一模型执行它们，`coverage.js` 记录视频哪些部分已经有口述，`shortcuts.js` 是快捷键层（Chrome 的写法和 Mac 符号、按物理按键匹配键盘事件、Chrome 和页面都有按键时谁优先、冲突检查、`pageShortcuts` 设置）。
- `src/popup/`、`src/options/`、`src/transcript/`、`src/guide/`、`src/welcome/` —— 工具栏弹出面板、设置页、文字稿页、API 密钥指南，以及首次使用时打开的欢迎页（先听一段示例，再选“免费开始”或自己的密钥）。
- `src/web/` —— 网页播放器（`site/play/`），由 `npm run build:web` 打包成 `site/play/player.js`，不含任何 `chrome.*` API：`app.js` 页面本身，`link.js` 解析 YouTube 链接，`youtube.js` 嵌入式播放器，`playback.js` 口述调度，`output.js` 和 `speech.js` 实时区域或 Web Speech 输出，`keys.js` 单键操作层，`model.js` Gemini 或中转，`store.js` 浏览器记住的内容，`i18n.js` 界面文字（英文和简体中文，来自 `scripts/locales/`）。
- `scripts/locales/` —— 全部界面文字，每种界面语言一个文件（`en.mjs` 为基准）；构建时生成 `_locales/`。
- `test/` —— 单元测试（`test/web-player.test.js` 覆盖网页播放器，`test/shortcuts.test.js` 覆盖快捷键层），以及 `test/e2e/e2e.py`：在无头 Chromium 里驱动真实扩展，对接假 YouTube 页面和模拟 Gemini API（127 项检查，含 axe 无障碍扫描）。
- `server/` —— SceneVoice Cloud 参考中转，一个 Cloudflare Worker，自带 README（协议说明）和 `server/test/` 下的测试；尚未部署。
- `site/` —— 项目网站（英文 + 简体中文；首页无需构建）。`site/play/` 是网页播放器页面（`index.html`、`play.css`，以及 `npm run build:web` 生成的 `player.js`）；`site/check.mjs` 是三个页面共用的无障碍门禁。

发布前用读屏软件测试的清单见 [CONTRIBUTING.md](./CONTRIBUTING.md)，其中也列出了 B 站的人工检查项。

## 路线图

1.0.0 之后已完成：按视频类型给默认值；面向中国内地的 B 站 + 通义千问版；诚实的第一分钟（欢迎页、一把 Key 描述所有网站、不再无声卡住）；口述不再压着对白、也不再互相打断；用量统计和每日上限；14 种界面语言；SceneVoice Cloud（可选的免 Key 路径：扩展里的 provider、`server/` 下的参考中转、隐私说明）；`site/` 下的项目网站；发布工程（带校验和的 GitHub Release、商店草稿、含无障碍门禁的 CI）。背后的计划见 `docs/plan-2026-11.zh-CN.md`。

接下来，按顺序：

1. 请视障用户实测（NVDA、JAWS、VoiceOver，中英文各一组），然后上架 Chrome 应用商店和 Microsoft Edge 加载项商店，并提供 Gitee 镜像方便中国内地下载。
2. SceneVoice Cloud 上线：中转部署到项目域名下，人人都有每日免费额度，付费档位养活它；能申请到的资助和捐赠额度一并争取。
3. 给创作者：把口述导出为文本或音轨，上传为 YouTube 的“口述（descriptive）”音轨。
4. 可选更有感情的中文语音（例如 CosyVoice），以及给低视力用户的大字号、高对比口述字幕模式。
5. 可编辑的角色记忆（"把穿红大衣的女人叫作 Maya"），按频道保存。
6. 共享人工修正过的口述，一个视频只需描述一次（先做版权评估）。
7. 手机端：安卓 App，或与手机厂商的读屏合作。中国的视障用户大多用手机看视频。
